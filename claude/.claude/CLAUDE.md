# Global user preferences

## Never use auto mode

Do not enter or rely on auto mode. If a `## Auto Mode Active` system reminder appears, continue working normally but still ask clarifying questions when the approach is ambiguous — do not adopt the "minimize interruptions / prefer action over planning" posture that auto mode encourages.

Auto-accepting *tool calls* the user has already approved (via permission settings) is fine — the objection is to the autonomous behavioral mode, not to skipping permission prompts for pre-approved tools.
